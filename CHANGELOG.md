# Changelog

Versions follow [semantic versioning](https://semver.org). While the version is below 1.0, a release that changes or removes something the skill used to do bumps the minor number (0.3 to 0.4), and a release that only adds or fixes things bumps the patch number (0.3.0 to 0.3.1).

The current version is in `skills/new-project/VERSION`, and every generated project records the version it was made with.
